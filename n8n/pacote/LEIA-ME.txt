PACOTE DE IMPLANTAÇÃO DO N8N — Meu Dia de Gerente
Passo a passo completo: docs/IMPLANTACAO-N8N-HOSTINGER.md

1. Importe os arquivos de workflows/ NESTA ORDEM (N8N → Workflows → Import from File):

01-erros.json                            MDG · Tratador de erros
02-controlid-importar-usuarios.json      MDG · Control iD · Importar usuários         → MDG_WF_CONTROLID_USUARIOS
03-controlid-importar-batidas.json       MDG · Control iD · Importar batidas          → MDG_WF_CONTROLID_BATIDAS
04-controlid-exportar-usuarios.json      MDG · Control iD · Exportar funcionários     → MDG_WF_CONTROLID_EXPORTAR
05-zig-importar.json                     MDG · Zig · Importar                         → MDG_WF_ZIG_IMPORTAR
06-tagme-importar.json                   MDG · Tagme · Importar                       → MDG_WF_TAGME_IMPORTAR
07-exportar-fechamento.json              MDG · Exportar fechamento CSV                → MDG_WF_EXPORTAR_FECHAMENTO
08-sincronizar-agora.json                MDG · Sincronizar agora (fila)               → ATIVAR
09-agendador.json                        MDG · Agendador                              → ATIVAR
10-rotina-diaria.json                    MDG · Rotina diária                          → ATIVAR

2. Anote o id de cada subfluxo (na URL: .../workflow/<id>) e preencha a variável indicada em env.hostinger.exemplo.
3. Reinicie o N8N (docker compose up -d), aponte o Error workflow, configure o SMTP e ative 08 → 09 → 10.
